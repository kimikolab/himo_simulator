# ヒモ太郎 バックストーリー設計書

最終更新日: 2026年4月6日

---

## 高校時代（18歳）

- 成績は中の下、部活もやらず帰宅部
- 友達は多くもなく少なくもなく。美咲とは同じクラスで普通に話す程度
- 将来の夢とか特になし。「まあ何とかなるっしょ」は当時から
- 美咲は真面目に勉強してて、ヒモ太郎は「すげえな」くらいの感覚

---

## 就職〜挫折（18〜20歳）

- 高卒で地元の中小企業に就職（営業 or 倉庫系）
- 最初は「社会人じゃん、俺」とちょっと浮かれる
- 現実：毎日残業、休日も呼び出し、上司は怒鳴るタイプ
- 半年くらいは耐えたが、ある朝どうしても体が動かなくなった
- 辞表を出したときの解放感が忘れられない
- **ここで「我慢して働き続ける」ことへの拒絶感が根付く**

---

## バイト転々期（20〜24歳）

- コンビニ → 遅刻が多すぎてシフト減らされ、居づらくなって辞める
- 居酒屋 → 最初は楽しかったが、酔客にキレかけて店長に怒られる
- 引越し → 体力的にきつすぎて3日で飛ぶ
- データ入力 → 単純作業に耐えられず、1ヶ月でフェードアウト
- 倉庫ピッキング → わりと続いた（半年）が、人間関係のトラブルで辞める

この期間で学んだこと：

- 正社員は論外、バイトすら続かない
- でも別に死にはしない（短期バイトの繰り返しでなんとか食える）
- 「俺は普通に働くのが向いてない」という確信

---

## ギャンブルとの出会い（21歳頃〜）

- バイト仲間に誘われてパチンコデビュー
- 初回でビギナーズラックの大勝ち → 「時給1,000円で8時間働くより効率いいじゃん」
- 以降、バイト代の大半がパチンコ or スマホ競馬に消えるようになる
- 本人は「トータルではプラス」と思い込んでいる（実際は大幅マイナス）
- ギャンブルの魅力：働かなくてもお金が増える（気がする）、刺激がある、時間が自由
- これが「働かずに金を得る」発想のベースになっている
- ヒモ生活に抵抗が薄い下地はここで作られた

---

## 一人暮らしの開始（23歳頃）

- バイト転々＋ギャンブル生活に、親の小言が日常化
- 「いつまでこんな生活するの」「ちゃんと働きなさい」
- 説教が嫌で、バイト代が少し貯まったタイミングで安アパートに引っ越し
- 「自由だ！」と思ったのも束の間、家賃という現実が毎月襲ってくる
- でも実家に戻る＝負けを認めること。意地でも戻らない
- 家賃を払うためにバイト → バイト代でギャンブル → 足りない → またバイト、の自転車操業

## 直前の状況（25歳・ゲーム開始時）

- 最後のバイト（倉庫）をクビになって1週間
- 貯金3,458円。来週の家賃12,500円が払えるかも怪しい
- 焦りはあるが、それ以上に「また同じこと繰り返すのか」という虚無感
- パチンコで取り返そうにも軍資金すらない
- SNSを開けば同級生の昇進・結婚報告。でも「大変そう」「ローンとか無理」としか思えない
- そこに美咲からの「久しぶり！ご飯行こうよ」
- 単純に暇だし、久しぶりの連絡が嬉しい。タダ飯にありつけるかもという淡い期待
- 「大手OLか、すげえな」とは思うが、この時点で搾取しようなんて考えてない
- **ヒモ生活は計画的に始まったのではなく、流されるままに始まった**

---

## 性格の核にあるもの

単なる怠け者じゃなくて、**一度ちゃんと頑張ろうとして折れた人間**。そしてギャンブルで「働かなくても金は手に入る」という歪んだ成功体験を持っている。だからこそ：

- 「働け」と言われると防衛反応が出る（あの地獄に戻りたくない）
- 楽観主義は本能的な自己防衛。深く考えると潰れるから考えない
- 美咲に奢ってもらう → ギャンブルで当てるのと同じ感覚で、罪悪感が麻痺しやすい
- 美咲が残業に耐えてるのを見て、尊敬と同時に「俺には無理」と線を引く
- 就職エンドで再チャレンジするとき、過去の挫折を乗り越える意味が出る

## ゲーム内での活かし方

| 場面 | 活用 |
|------|------|
| **導入（intro.rpy）** | バイト転々＋就職挫折の回想を挟む。「また同じだ」感。美咲への連絡は打算じゃなく暇と嬉しさ |
| **ギャンブル行動** | プレイ中の選択肢として実装。金欠時に「パチンコで取り返す」か「美咲に頼る」かの分岐 |
| **SNS閲覧** | 同級生の投稿に対する反応に深みが出る（羨望＋「でも大変そう」の防衛） |
| **求人情報を見る** | 「前もこういうの見て応募して…」のフラッシュバック |
| **美咲の疑念イベント** | 「利用してる？」に対して、ギャンブル感覚で人に頼ってきた自分の弱さを認める重さ |
| **初めてお金をもらう** | ここで初めて「これ、ヒモってやつじゃね？…まあいっか」とヒモの自覚が芽生える |
| **就職ルート** | 過去の挫折＋ギャンブル依存を断ち切る意味が加わり、再チャレンジの重みが増す |
| **親との関係** | 電話イベント等で「帰ってこい」と言われても意地で断る。でも内心は… |
