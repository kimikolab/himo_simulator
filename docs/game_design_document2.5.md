## プロジェクト概要

### 基本情報

**タイトル**: ヒモ男シミュレーター  
**ジャンル**: 恋愛シミュレーション / リソース管理ゲーム  
**プラットフォーム**: PC (Ren'py 8.x)  
**配信**: Steam  
**対象年齢**: 17歳以上（R-17）  
**開発期間**: 4-6ヶ月（Phase 1は1-2週間）  
**想定プレイ時間**: Phase 1（30分-1時間）/ 完成版（3-5時間）

### コアコンセプト

> 複数の女性との関係を同時進行しながら、バレないように生活費を確保する背徳的なシミュレーションゲーム。  
> プレイヤーの選択が問われる、大人のリソース管理ゲーム。

### ターゲット層

- 恋愛シミュレーション好き（20-35歳男性）
- ダークなテーマ・倫理的ジレンマを楽しめる層
- 戦略性のあるシミュレーションゲーム好き
- 実況・配信向けのリプレイ性を求める層

## v2.5での改善点

### v2.0からの主な変更

チャッピーからのフィードバックを受けて、以下を改善しました：

#### 1. パラメータ表示の簡略化

**変更前（v2.0）**
```
表示パラメータ: 6個
- 所持金
- 体力
- 魅力
- 清潔感
- 信頼度
- 依存度

問題点: 情報過多で「管理ゲー感」が強すぎる
```

**変更後（v2.5）**
```
表示パラメータ: 3個のみ
- 所持金 ← 最重要
- 信頼度（美咲）
- 依存度（美咲）

裏パラメータ（表示しない）:
- 体力 → 低いとイベント発生
- 清潔感 → 美咲の反応に影響
- 魅力 → Phase 1では固定

メリット:
✅ 初見プレイヤーの負担が減る
✅ 見た目がシンプル
✅ でも裏では機能している
```

#### 2. 美咲の疑念イベント追加

**追加理由**
- 美咲が「都合のいい女」に見えないようにする
- プレイヤーに「奪っている側」という自覚を持たせる
- ストーリーに緊張感を追加

**実装内容**
```
5日目または6日目に発生:
美咲「私のこと...利用してる？」

プレイヤーの選択肢:
1. 正直に認める → 信頼+10、正直カウント+2
2. 誤魔化す → 信頼-5、嘘カウント+1
3. 冗談でごまかす → 違和感蓄積

効果:
- エンディング分岐に影響
- プレイヤーの罪悪感を刺激
- 美咲のキャラクター性が深まる
```

#### 3. ヒモ適性診断システム（非表示）

**実装内容**
```
裏で集計するデータ:
- 楽な選択を選んだ回数
- お金を要求した回数
- 嘘をついた回数
- 正直に話した回数
- 働くことを避けた回数
- 美咲を気遣った回数

エンディングで診断結果表示:
「タイプ: 筋金入りのヒモ」
「楽な選択: 8回」
「嘘: 3回」
...

メリット:
✅ リプレイ性向上
✅ 実況映え（「俺、筋金入りのヒモwww」）
✅ 考察勢が喜ぶ
✅ 実装コストが低い
```

#### 4. 就職ルートの調整

**変更前（v2.0）**
```
Phase 1から就職ルートを実装
```

**変更後（v2.5）**
```
Phase 1では匂わせるのみ:
- 求人情報を見るイベント
- 「働くって選択肢もあるんだよな...」
- 「まあ、また今度考えよう」

本格的な就職ルートはPhase 2以降で実装

理由:
- Phase 1の実装範囲を抑える
- 焦点を「美咲との関係」に絞る
```

## 開発方針

### 最重要原則：完成を最優先

**段階的開発アプローチ**
```
Phase 1（1-2週間）: 7日間プロトタイプ（v2.5）
  ↓ 完成・テストプレイ・フィードバック
Phase 2（3-4週間）: 30日間版（サブキャラ・ナンパ追加）
  ↓ 完成・バランス調整
Phase 3（4-6週間）: 完成版（全キャラ・全エンディング）
  ↓ Steam早期アクセス or 製品版リリース
```

**チャッピーからの助言**
```
「この企画書の1/3を捨てて、7日間版を完成させる」

完成した7日間プロトタイプ
> 
未完成の30日間版
>
企画だけの完全版

ここまで来たら、完成しない未来の方が不自然。
```

## ゲームコンセプト

### テーマ

**表面**: 恋愛・生活シミュレーション  
**本質**: リソース管理・リスクマネジメント  
**問いかけ**: 「あなたはどこまで堕ちられるか？」

### セールスポイント

1. **倫理観を問う選択肢**
   - ヒモとして生きるか、真面目に働くか
   - 一人を大切にするか、複数から搾取するか
   - 嘘をつくか、正直に生きるか

2. **緊張感のあるリスク管理**
   - バレたら全てを失う
   - 複数女性の管理と時間配分（Phase 2以降）
   - 月末の家賃支払いプレッシャー

3. **複数エンディング**（Phase 1: 3種類 / 完成版: 8種類）
   - 真っ当な生活エンド
   - プロヒモエンド
   - 破滅エンド
   - 選択によって大きく変わる結末

4. **リアルな生活シミュレーション**
   - 家賃・食費・体力管理
   - 時間帯による行動の違い（朝・昼・夜）
   - 週末と平日の違い

5. **深いキャラクター性**
   - 各女性に明確な性格と背景
   - 信頼度・依存度の2軸管理
   - 関係ステージによる変化

6. **違和感の積み重ね**（v2.5強化）
   - 小さな疑念が蓄積していく心理描写
   - バレる前の緊張感演出
   - 「私のこと、利用してる？」という直球の質問

7. **ヒモ適性診断**（v2.5新規）
   - プレイヤーの行動を裏で集計
   - エンディングで診断結果表示
   - リプレイ性と実況映え

## コアゲームシステム

### 時間管理システム

**1日 = 朝・昼・夜の3ターン**
```
朝（6-12時）: 準備・身支度の時間
  - 女性は出勤前/仕事中
  - 連絡の返信率: 低〜中

昼（12-18時）: 最も自由に動ける時間
  - 女性は昼休み/仕事中
  - 連絡の返信率: 中〜高
  - 街に出やすい

夜（18-24時）: デート・交流の中心時間
  - 女性は仕事終わり
  - 連絡の返信率: 高
  - デート成功率が最も高い
```

**曜日の概念**
- 平日（月-金）: 女性は忙しい、会いにくい
- 週末（土日）: 女性は時間がある、会いやすい

### プレイヤーパラメータ（v2.5版）

#### 表示パラメータ（3つのみ）

| パラメータ | 初期値 | 最大値 | 説明 |
|---------|-------|-------|------|
| **所持金** | 3,458円 | 無制限 | 生活費・娯楽費 |
| **信頼度（美咲）** | 30 | 100 | 高いほどお金をもらいやすい |
| **依存度（美咲）** | 10 | 100 | 高いほど束縛される |

#### 裏パラメータ（表示しない）

| パラメータ | 初期値 | 機能 |
|---------|-------|------|
| 体力 | 100 | 低いとイベント発生、行動制限 |
| 清潔感 | 50 | 美咲の反応に影響 |
| 魅力 | 50 | Phase 1では固定 |

**v2.5の改善点**
```
Before: 6個のパラメータを常時表示
→ 情報過多、管理ゲー感が強い

After: 3個のみ表示、裏で機能
→ シンプル、でも深い

メリット:
✅ 初見プレイヤーの負担軽減
✅ UI がスッキリ
✅ 重要な数値に集中できる
```

#### 隠しパラメータ（Phase 2以降）
- 罪悪感: 行動で蓄積、エンディング分岐に影響
- 評判: SNSでの噂、悪化すると出会いが困難
- ストレス: 高いと体力消費増加

#### 月次固定費
- 家賃: 50,000円/月（Phase 1では12,500円/週）
- 通信費: 3,000円/月（Phase 1では750円/週）
- 食費: 約10,000円/月（行動で消費）

### 女性パラメータ（各キャラ共通）

#### 2軸管理システム

**信頼度（0-100）**
```
低い: 会ってくれない、お金をくれない
中程度: 普通の友達関係
高い: 金銭援助を受けやすい

▼ 上げる方法:
- 正直に話す
- 約束を守る
- 励ます、話を聞く

▲ 下げる要因:
- 嘘がバレる
- 連絡を無視
- お金ばかり要求
```

**依存度（0-100）**
```
低い: 自立した関係、束縛されない
中程度: 適度に頼られる
高い: 束縛される、他の女とバレやすい

▼ 上げる方法:
- 甘える
- 頻繁に会う
- 弱みを見せる

⚠ リスク:
- 高すぎると GPS確認
- 他の女性とバレやすい
- 行動の自由度が下がる
```

#### 関係ステージ
```
Stage 1: 知り合い
  - 連絡先交換済み
  - デート可能

Stage 2: 友達
  - 気軽にデート
  - 食事代を出してもらえることも

Stage 3: いい雰囲気
  - 金銭援助開始（小額）
  - お金の相談ができる

Stage 4: 恋人
  - 定期的な金銭援助
  - 高額援助の可能性
  - 束縛が強くなる

Stage 5: 同棲（Phase 2以降）
  - 家賃免除
  - 超高額援助
  - 超高束縛（他の女とほぼ無理）
```

### 金銭援助システム

#### 援助タイプと金額

| タイプ | 金額目安 | 必要信頼度 | 依存度変化 | 頻度 |
|-------|---------|----------|-----------|------|
| デート代奢り | 2,000-5,000円 | 40+ | +2 | 毎回可能 |
| お小遣い（小） | 3,000-10,000円 | 35+ | +8 | 週1-2回 |
| お小遣い（中） | 8,000-20,000円 | 55+ | +12 | 週1回 |
| お小遣い（大） | 15,000-30,000円 | 75+ | +15 | 月1-2回 |
| 家賃援助 | 30,000-50,000円 | 80+ | +20 | 月1回 |

**重要な制約（Phase 2以降）**
```
高額援助には代償がある:
- 時間拘束「明日の夜、必ず会う約束」
- 行動報告「今日何してた？」
- 依存度大幅UP（束縛リスク）

→ 金 = 万能ではない
→ 自由 vs 安定のトレードオフ
```
