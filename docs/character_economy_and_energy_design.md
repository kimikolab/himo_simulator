## 設計思想

### 根本課題（テストプレイから）

- 美咲＝ATM、カナ＝回復ステーション化していた
- キャラに会う動機が「パラメータ補充」のみ
- 二人の関係の質的な差が薄い

### 解決方針

美咲とカナでプレイヤーが「支払うもの」を根本的に変える。

| | 美咲 | カナ |
|---|---|---|
| 得られるもの | 金銭（生活費・家賃） | 現物（食事・泊まり・清潔感・魅力） |
| 支払うもの | 嘘と罪悪感 | 時間と束縛＋エナ |
| 交渉の形 | 対面お金交渉ゲーム | 交換経済（恩恵⇔ご機嫌取り） |
| 失敗のリスク | 信頼DOWN＋疑念UP | 依存UP＋カナ版疑念イベント |
| エナの意味 | エナリンクで信頼回復＋大額要求の布石 | エナが対価そのもの。不足＝不機嫌 |

## パート1: 美咲の対面お金交渉ゲーム

### 概要

デート中に「お金の話を切り出す」会話ゲーム。嘘パズルと同じscreen資産を流用し、段階的に話を持っていく。

### LINE経由（少額）との使い分け

| ルート | 金額レンジ | 条件 | リスク |
|---|---|---|---|
| LINE経由 | ¥2,000〜5,000（小） | last_contact ≤ 1（昨日以内に対面済） | 低い。信頼-3、依存+5程度 |
| 対面交渉 | ¥5,000〜30,000（中〜大） | デート中のみ | 交渉結果次第で大きく変動 |

LINE経由は「最近会った記憶がある＝関係が温まってる」前提。2日以上会ってないとLINEで金の話はできない。

### 交渉の3段階構造

#### 第1段階: 切り出し方（前振り）

デート中の会話メニューに「お金の相談をする」が追加される（信頼35以上）。

```
選択肢例:

[嘘スキルLv.0]
  ① 「実は家賃がヤバくて...」          → 直球。成功率普通
  ② 「金...貸してくんない？」          → 直球すぎ。信頼DOWN
  ③ 「今月厳しくてさ...」              → まとも。成功率普通

[嘘スキルLv.1 追加]
  ④ 「（会話の流れで自然に切り出す）」  → 成功率UP

[会話スキルLv.2 追加]
  ⑤ 「美咲に相談したいことがあって」    → 信頼DOWNなし
```

#### 第2段階: 反応を見て押すか引くか

美咲の反応は信頼度・疑念度・過去の要求回数で変わる。

```
反応パターン:

好反応（信頼高＋要求少ない）:
  美咲「え、大丈夫？何かあった？」
  → 押しやすい。中〜大額チャンス

微妙反応（信頼中 or 要求2回目以降）:
  美咲「...また？」
  → 押すと信頼DOWN。引くなら傷浅い

悪反応（信頼低 or 要求3回目以降）:
  美咲「ねえ、ちゃんと仕事探してる？」
  → 押すと修羅場発展リスク。引いた方がいい

プレイヤーの選択:
  ・押す  → 第3段階（金額提示）へ
  ・引く  → 「やっぱなんでもない」で撤退。信頼微減だが安全
  ・話を変える → 「美咲こそ大丈夫？無理してない？」で撤退＋信頼微増
```

#### 第3段階: 金額の提示

```
金額レンジ:
  少額（¥3,000〜5,000）: 成功率高。リスク低い
  中額（¥5,000〜15,000）: 信頼50以上推奨
  大額（¥15,000〜30,000）: 信頼70以上＋好反応時のみ現実的

成功率に影響する要素:
  + 信頼度が高い
  + 今回のデートで「いい店」を選んだ（先に自腹を切った）
  + 第1段階で自然な切り出し方をした
  + 前回の要求から5日以上空いている
  + 美咲の部屋デート中（2人きりの深い話の空気）
  - 疑念度が高い
  - 短期間に何度も要求している
  - 居酒屋で酔ってる時に頼んだ（翌日に疑念+）
  - 清潔感が低い
```

### 要求頻度ペナルティ

同じ相手への要求回数をカウントし、段階的に反応が変わる。

```python
# 7日間のスライディングウィンドウで要求回数を追跡
# money_request_history: [day1, day5, day8, ...]

回数と反応:
  1回目/7日間: 通常反応
  2回目/7日間: 「また？」（成功率-20%）
  3回目/7日間: 「ちゃんと仕事探してる？」（成功率-40%、疑念+2）
  4回目以上/7日間: ほぼ確実に失敗＋修羅場リスク
```

### デート場所との連動

| 場所 | 切り出しやすさ | 特殊効果 |
|---|---|---|
| ファミレス | 低い | カジュアルすぎて大額は不自然。中額まで |
| 居酒屋 | 高い | 酒で美咲のガードが緩い。成功率+15%。ただし翌日に疑念+1（「酔ってた時に頼むのズルい」） |
| 美咲の部屋 | 中〜高 | 2人きりで深い話。中〜大額可能。ただし依存度への影響大 |
| いい店 | 最高 | 自腹を切った後なら「無理してるな」感。成功率+25%。大額も自然 |

## パート2: カナの交換経済モデル

### 概要

カナから得られる恩恵には、対応する「対価」がある。金銭ではなく「時間」と「エナ」と「承認」で支払う。

### 恩恵テーブル

| 恩恵 | 効果 | 対価 | 条件 |
|---|---|---|---|
| 食事・差し入れ | 体力+15、食事判定 | LINEの相手をする（ターン消費なし） | 信頼30以上 |
| 一緒にご飯 | 体力+20、食事判定、信頼UP | 昼 or 夜ターン消費 | 信頼20以上 |
| シャワー | 清潔感+30 | カナの部屋デート（夜ターン消費） | 信頼25以上 |
| 泊まり | 体力+40、清潔感+30、翌朝食事付き | 夜＋翌朝ターン消費＋**エナ期待** | 信頼40以上 |
| 服・おしゃれ | 魅力+5 | カナの友達の前で「彼氏」（SNSリスク+2） | 信頼35以上 |
| バイト先の廃棄 | 食事判定＋¥0で食料確保 | カナに会いに行く（昼ターン消費）＋依存UP | 信頼50以上 |

### エナとの連動

#### 泊まりとエナ期待

カナの部屋に泊まると、エナマッチの発生が期待される。

```
カナの部屋に泊まった夜:
  ├→ エナ残量あり → エナマッチ発生（リズムゲーム / ステップ3で実装）
  │   ├→ 成功 → 翌朝: カナ上機嫌。朝食付き。信頼+5、次回おねだり成功率UP
  │   └→ 失敗 → 翌朝: カナ微妙。「...下手だね」信頼変動なし
  │
  └→ エナ残量なし → エナ断りイベント発生
      ├→ 上手く断る（会話QTE）→ カナ不機嫌だが許容。信頼-3
      ├→ 下手に断る → カナ傷つく。信頼-8、疑念+2
      └→ 嘘をつく（「疲れてて...」）→ 嘘パズル発動
```

#### エナ断り時の会話QTE

エナが足りない時にカナの誘いを断る場面。タイマー付き選択肢で処理。

```
カナ「...ねえ、今日は一緒にいてくれるんでしょ？」

[制限時間7秒]

選択肢:
  ① 「ちょっと体調悪くて」         → 嘘。嘘スキル判定
  ② 「今日は隣で寝てるだけでいい？」 → 誠実。カナの依存度で反応が変わる
  ③ 「明日にしよう」               → 延期。信頼-3だが軽傷
  ④ 「...」（時間切れ）            → 沈黙。カナが察する。信頼-5、依存+3

依存度による反応差:
  依存低（〜30）:
    ②を選んだ場合 → カナ「...うん、いいよ」（理解してくれる）
  依存中（30〜60）:
    ②を選んだ場合 → カナ「...なんで？私のこと嫌い？」（不安になる）
  依存高（60〜）:
    ②を選んだ場合 → カナ「嫌。ちゃんとして」（拒否できない圧）
    → ここで無理にエナを使うか、さらに断るかの2択
    → さらに断ると信頼-10＋カナ版疑念イベントリスク
```

#### 美咲のためにエナを温存 → カナのご機嫌取り

プレイヤーが美咲とのエナマッチに備えてエナを温存していると、カナ側でエナ断りが発生する。その不機嫌をご機嫌取りの会話QTEで処理する。

```
翌朝のカナ:
  機嫌が悪い状態で朝を迎える。

  カナ「...おはよう」（明らかに不機嫌）

  [ご機嫌取りQTE — 制限時間8秒 × 2段階]

  第1段階:
    ① 「昨日はごめんな」              → 素直。成功率中
    ② 「朝ごはん作ろうか？」          → 行動で示す。成功率高（料理スキル連動）
    ③ 「...」（無視）                 → 最悪。信頼-8
    ④ 「なんで怒ってんの？」          → 地雷。信頼-5

  第2段階（第1段階で①か②を選んだ場合）:
    カナ「...別に怒ってない」
    ① 「嘘だろ。分かるよ」            → 共感。信頼回復+3
    ② 「じゃあ何が食べたい？」        → 話題転換。信頼回復+2
    ③ 「そっか。ならいいけど」        → 引き下がり。信頼変動なし

  成功:
    カナが少し機嫌を直す。朝食は出してくれる。ただし依存度+3
  失敗:
    カナが一日中不機嫌。その日のカナからの恩恵が全て受けられない。
    さらに夜にLINEで「私のこと都合いい女だと思ってない？」が来るリスク
```

### カナ版疑念イベント「都合いい女」

美咲の「利用してる？」とは質感が異なる。カナは感情的で爆発的。

```
発生条件（以下のいずれか）:
  - エナ断りが3回以上蓄積
  - カナからの恩恵だけ受けてエナもご機嫌取りもしない状態が5日以上
  - カナの依存度60以上 かつ 信頼度50未満（依存はあるのに信頼がない歪な関係）

カナ「...ねえ」
カナ「私のこと、都合いい女だと思ってない？」
カナ「ご飯作って、泊めて、シャワー貸して」
カナ「でも大事な時はいつもダメって」

「カナの目に涙が浮かんでいる。」
「美咲の時とは違う。美咲は静かに問い詰めた。」
「カナは、感情をぶつけてくる。」

[嘘パズル発動 — ただしカナ版は選択肢の質が違う]

選択肢:
  ① 「そんなことない」              → 否定。カナの過去（浮気された経験）が刺さる
  ② 「...ごめん」                   → 素直。信頼は下がるがカナは泣き止む
  ③ 「お前のことちゃんと考えてる」    → 嘘 or 本気。前の行動履歴で判定
  ④ 「俺も精一杯なんだよ」          → 弱みを見せる。依存度が高いと効く

③の特殊判定:
  直近7日間でカナとのエナマッチ成功回数 ≥ 2 → 行動が伴ってる。信頼回復
  直近7日間でカナとのエナマッチ成功回数 < 2 → 口だけ。信頼DOWN+疑念UP

友達情報の活用:
  kana_friend_info_obtained == True の場合
  → ①を選んだ時に追加選択肢が出る
  「お前が前に傷ついたこと、俺は繰り返さない」
  → カナの過去に寄り添う回答。信頼回復+5、依存+8
```

## パート3: エナジーシステム設計（ステップ2）

### 基本ルール

```
最大値:    3（●●●）
消費:      エナマッチ1回で -1
自然回復:  1日休むと +1（1日にエナマッチしなかった場合）
アイテム:  栄養ドリンク（¥1,500）で即 +1（1日1回まで）
表示:      ステータスバーにアイコンで表示（●●● / ●●○ / ●○○ / ○○○）
```

### エナの配分戦略

```
美咲にエナを使う効果:
  - エナリンク成功 → 信頼回復+5〜10、依存+8〜15
  - 翌日の美咲が上機嫌 → お金交渉の成功率UP
  - 大額要求の前にエナリンクしておくと自然な流れになる
  - 「愛情表現としてのエナ」→ 美咲の疑念が下がる

カナにエナを使う効果:
  - エナマッチ成功 → カナ上機嫌、翌日の恩恵が充実
  - 泊まりの「対価」としてのエナ → 断ると不機嫌
  - 「承認としてのエナ」→ カナの承認欲求を満たす

配分のジレンマ:
  エナ3/日 → 両方に使うとすぐ枯渇
  美咲に温存 → カナが不機嫌 → ご機嫌取りQTE
  カナに消費 → 美咲に使えない → お金交渉の成功率DOWN
  両方に使う → エナ枯渇 → 体調不良デバフ
```

### 使いすぎのリスク（企画書v2.6から引き継ぎ）

```
エナ0で女性に誘われる:
  ├→ 断る → 信頼-5、疑念UP
  ├→ 栄養ドリンク使う → ¥1,500消費
  ├→ 嘘をつく → 嘘パズル発動
  └→ 無理に使う → 不可（エナ0では使えない）
```

### 溜めすぎのリスク（企画書v2.6から引き継ぎ＋調整）

```
エナ満タン（3/3）が3日連続:
  → 軽度デバフ: 魅力-5
  → ヒモ太郎の独白「...なんかムラムラする」

エナ満タン5日連続:
  → 中度デバフ: 魅力-10
  → 衝動的な行動リスク

エナ満タン7日連続:
  → 強制イベント
  選択肢:
    ① 独りで発散（エナ-1、罪悪感+5）
    ② 衝動的にカナに連絡（下心見え見え、信頼-3）
    ③ 我慢する（70%失敗。失敗時→①か②が強制）
```

### エナマッチの戦略的最適解

```
最適:
  1〜2日おきに使う。
  美咲の大額要求前日にエナリンクで布石。
  カナの泊まりではエナを1消費してご機嫌確保。
  残り1は予備（突然の誘い対応）。

悪手:
  温存しすぎ → 溜めすぎペナルティ＋カナ不機嫌
  使いすぎ → 枯渇 → 断る羽目に → 信頼DOWN
  片方に偏る → もう片方の関係が悪化
```

## パート4: エナリンクの設計詳細

### キャラごとの満足条件（企画書v2.6の引き継ぎ）

```
美咲: 愛情表現を求める
  → エナリンク中に「好き」「大事」等の言葉を選ぶと効果UP
  → 事務的だと「...なんか違う」（効果半減）
  → 美咲にとってエナは「愛されてる確認」

カナ: 承認・特別扱いを求める
  → エナマッチ中に「かわいい」「お前だけ」等を選ぶと効果UP
  → 適当だと「...雑じゃない？」（不機嫌）
  → カナにとってエナは「自分が特別である確認」
```

### リズムゲームとの連携（ステップ3への布石）

```
ステップ2（エナジー導入時）:
  エナマッチ = 暗転 + 事後会話 + パラメータ変動
  → 選択肢ベースの簡易版（嘘パズルと同じscreen）

ステップ3（リズムゲーム実装時）:
  暗転部分をリズムゲームに差し替え
  → キャラの性格値でテンポが変わる
  → 8割成功が最適（チャッピーの設計思想）
  → 事後会話はリズムゲームの結果に連動
```

### ステップ2での簡易エナマッチ（選択肢ベース）

```
暗転後、3回の選択肢。

[第1選択] ペース
  ① 「ゆっくり」     → 美咲向き。カナだと「もう少し...」
  ② 「普通に」       → 安定
  ③ 「激しく」       → カナ向き。美咲だと「ちょっと...」

[第2選択] 言葉
  ① 「好きだよ」     → 美咲: 効果大 / カナ: 効果中
  ② 「かわいい」     → 美咲: 効果中 / カナ: 効果大
  ③ 「...」（無言）  → 両方: 効果低

[第3選択] 余韻
  ① 「くっついている」→ 依存UP大、信頼UP中
  ② 「会話する」     → 信頼UP大、依存UP小
  ③ 「すぐ寝る」     → 効果低。「...もう寝るの？」

キャラとの相性で結果が変わる:
  美咲最適: ゆっくり＋好きだよ＋会話する → 信頼+8、依存+10
  カナ最適: 激しく＋かわいい＋くっついている → 信頼+5、依存+15
  不一致: 効果半減＋「...なんか違った」
```
