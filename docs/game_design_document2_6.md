## プロジェクト概要

### 基本情報

**タイトル**: ヒモ男シミュレーター  
**ジャンル**: 恋愛シミュレーション / リソース管理ゲーム  
**プラットフォーム**: PC (Ren'py 8.x)  
**配信**: Steam  
**対象年齢**: 17歳以上（R-17）  
**開発期間**: Phase 1（1-2週間）/ Phase 2（7週間）/ Phase 3（6-8週間）  
**想定プレイ時間**: Phase 1（30分-1時間）/ Phase 2（2-3時間）/ 完成版（3-5時間）

### コアコンセプト

> 複数の女性との関係を同時進行しながら、バレないように生活費を確保する背徳的なシミュレーションゲーム。  
> プレイヤーの選択が問われる、大人のリソース管理ゲーム。

### ターゲット層

- 恋愛シミュレーション好き（20-35歳男性）
- ダークなテーマ・倫理的ジレンマを楽しめる層
- 戦略性のあるシミュレーションゲーム好き
- 実況・配信向けのリプレイ性を求める層

## スキルシステム（Phase 2）

### コンセプト

**「ヒモとして成長する」要素**

- プレイヤーの選択で成長方向が変わる
- 各スキルで異なるエンディング解放
- 2周目以降に引き継ぎ可能
- リプレイ性とやり込み要素

---

### 1. 料理スキル

**コンセプト**: 気が向いた時にパスタ作る

| レベル | 条件 | 特徴 | 効果 |
|-------|------|------|------|
| Lv.0 | 初期 | レシピ通り | 信頼+3、依存+5 |
| Lv.1 | 3回 | コツを掴んだ | 信頼+5、依存+8 |
| Lv.2 | 10回 | アレンジできる | 信頼+8、依存+12 |

**料理の種類**（Phase 2）
- パスタ、目玉焼き、チャーハン（Lv.0）
- オムレツ（Lv.1）
- カルボナーラ、オムライス（Lv.2）

---

### 2. 親密度スキル（夜のテクニック）

**コンセプト**: Steam対応の暗示表現

| レベル | 条件 | 反応 | 依存度上昇 |
|-------|------|------|-----------|
| Lv.0 | 初期 | "...まあ、うん" | +3 |
| Lv.1 | 3回 | "...悪くなかった" | +8 |
| Lv.2 | 10回 | "...また、したい" | +15 |

**実装**
- 暗転 + 事後の会話
- 直接的な描写なし
- 依存度を大きく上げる

---

### 3. 会話スキル（話術+気遣い）

**コンセプト**: 相手を理解し、信頼を得る

| レベル | 条件 | 効果 | 信頼度上昇 |
|-------|------|------|-----------|
| Lv.0 | 初期 | 普通の会話 | 基本値 |
| Lv.1 | 5回 | 楽しませられる | +50% |
| Lv.2 | 15回 | 悩みを引き出せる | +100% |

**成長条件**
- 「共感」「励まし」「気遣い」選択肢

---

### 4. 嘘スキル（口八丁手八丁）

**コンセプト**: 複数女性管理の必須スキル

| レベル | 条件 | 成功率 |
|-------|------|--------|
| Lv.0 | 初期 | 30% |
| Lv.1 | 成功5回 | 50% |
| Lv.2 | 成功15回 | 70% |

**リスク**
- 失敗すると疑念蓄積
- 罪悪感増加

---

### 引き継ぎシステム

**2周目以降でスキル引き継ぎ可能**

```
1周目: 料理特化 → 美咲エンド
  ↓
2周目: 料理Lv.2引き継ぎ → カナ攻略
  ↓
3周目: 全スキル引き継ぎ → プロヒモエンド
```

**効果**

- リプレイ性向上

## 精力システム（Phase 2）

### コンセプト

```
親密な行為 = 強力だが限りあるリソース
  ↓
使いすぎ → 枯渇
溜めすぎ → 暴走
  ↓
「適度に使う」が最適解
```

**ゲームデザイン的効果**
- 複数女性管理の戦略性が劇的に向上
- バランス感覚が求められる
- リアリティの向上

---

### 基本ルール

```python
最大値: 3回（●●●）
消費: 親密イベント1回で-1
回復: 1日休むと+1
アイテム: 栄養ドリンク（1500円）で即+1
```

### 使いすぎのリスク

```
気力0で女性に誘われる
  ↓
断る（-5信頼、疑念蓄積）
or
栄養ドリンク使う（-1500円）
or
嘘をつく（嘘スキル判定）
```

### 溜めすぎのリスク★v2.2追加

```
満タン3日連続 → 軽度デバフ（魅力-5）
満タン5日連続 → 中度デバフ（魅力-10）
満タン7日連続 → 強制イベント
  ↓
選択肢:
1. 独りで発散（気力-1、罪悪感+5）
2. 衝動的に連絡（下心見え見え、信頼-3）
3. 我慢する（70%失敗）
```

### 戦略性

```
最適: 1-2日おきに使う
悪例: 温存しすぎ → 暴走 → 無駄な消費
悪例: 使いすぎ → 枯渇 → 断る羽目に
```
