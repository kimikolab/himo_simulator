## 9. 備考

- 現在のコードは全箇所 `scene bg_placeholder` のため、背景差し替え時は各ファイルの `scene` 文を一括置換する
- キャラクター立ち絵の `show` / `hide` 文はコードに未実装のため、素材導入時にセリフの前後に `show misaki happy` 等を追加する作業が必要
- BGM/SE は `game/audio/` ディレクトリ（空で存在済み）にファイルを配置し、`play music` / `play sound` 文をコードに追加する
- `options.rpy` の `config.main_menu_music` のコメントアウトを解除してタイトルBGMを設定する
