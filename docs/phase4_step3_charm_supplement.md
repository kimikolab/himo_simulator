# Phase 4 Step 3 追補: 魅力ステータスの活用

**最終更新日**: 2026年4月4日

## 概要

魅力（`player["charm"]` + `energy_charm_bonus`）を3箇所の判定に組み込む。現状はナンパ成功率のみで使われており、カナ出会い後は実質死にステータスになっている。

**有効魅力の算出**（共通で使う）:

```
effective_charm = player["charm"] + energy_charm_bonus
```

---

## 追加1: えなマッチ段階1のムード初期値ボーナス

**変更箇所**: `systems/ena_match.rpy` の `ena_match` ラベル冒頭

ムードポイントの初期値を、魅力に応じて0〜2の範囲でボーナス付与する。

```
_mood の初期化時:
  effective_charm が 70以上 → _mood = 2（スタート時点で有利）
  effective_charm が 55以上 → _mood = 1
  それ以外             → _mood = 0（現状と同じ）
```

**設計意図**: 服や香水で魅力を上げておくと、えなマッチの段階1〜2で多少ミスってもムード4に到達しやすくなる。ただしムード初期値だけで成功が確定するほどではない（最大+2なので、段階1〜2で+2以上稼がないとムード4には届かない）。

## 追加2: デートの奢り判定に魅力補正

**変更箇所**: `misaki_events.rpy` の `misaki_date` 内、デート後の会計処理

現状は `misaki["trust"] >= 45` で美咲が奢ってくれる。ここに魅力補正を加える。

```
変更前: misaki["trust"] >= 45 で奢り
変更後: misaki["trust"] >= (45 - charm_bonus) で奢り

charm_bonus の算出:
  effective_charm が 70以上 → charm_bonus = 10
  effective_charm が 55以上 → charm_bonus = 5
  それ以外             → charm_bonus = 0
```

つまり魅力70以上なら信頼35でも奢ってもらえる。信頼が低い序盤でも身だしなみに投資すれば早期に奢りを引ける。

**カナのデート**: カナは基本的に奢ってくれる設計（大学生で金はないが奢りたがる性格）なので、魅力補正は不要。カナ側は変更しない。

## 追加3: 対面お金交渉の成功率に魅力補正

**変更箇所**: `parameter_system.rpy` の交渉成功率計算

現状の成功率計算:

```
rate = base_rate + loc_bonus - weekly_pen - susp_pen
```

ここに魅力ボーナスを追加:

```
charm_negotiation_bonus:
  effective_charm が 70以上 → +10
  effective_charm が 55以上 → +5
  それ以外             → +0

rate = base_rate + loc_bonus + charm_negotiation_bonus - weekly_pen - susp_pen
```

**デバッグログ**: 交渉判定ログに `charm_bonus=[値]` を追加して追跡可能にする。

## 将来の作業メモ

- **魅力依存のテキスト変化**: デート中の女の子の反応が魅力の高低で変わる。高魅力だと「今日なんかかっこいいね」、低魅力だと反応がそっけない、等。テキストプールを魅力帯（低/中/高）で分岐させる。大量のテキスト追加が必要なのでフル版で対応。
- **清潔感との複合判定**: 魅力が高くても清潔感が低いと効果が半減する、みたいな複合条件。リアリティ向上だがデモ版では過剰。
