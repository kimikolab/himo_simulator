## 背景と課題

### デバッグログから見えた問題

3回のテストプレイ（20260307）で共通して確認された構造的問題:

1. **10日目〜25日目が空洞**: イベントがほぼ発生せず、同じルーティンの繰り返し
2. **美咲＝ATM、カナ＝回復ステーション化**: キャラに会う動機が「パラメータ補充」のみ
3. **安全ルーティンの確立**: 朝に美咲にお金要求→昼は適当→夜にデート、が崩れない
4. **嘘をついた回数が全プレイ0回**: 修羅場・追い詰め場面が発生しない
5. **所持金が青天井**: ログ1では¥50,000超、リスクゼロ状態で後半を消化
6. **カナが空気になりやすい**: 意識的に関わらないと信頼が下がり続ける

### 解決方針

「ゲーム側からプレイヤーのルーティンを崩しに行く」設計を中盤に投入する。

## A. 中盤イベント

### A-1. 中盤前半（9〜15日）— 最初の揺さぶり

#### イベント①: 美咲「最近忙しいの？」

- **種別**: パラメータトリガー
- **発生条件**: カナ出会い済み＋美咲last_contact ≥ 3（3日以上連絡なし）
- **演出**: SNS受動通知で「美咲がLINEステータスメッセージを変えた」が先に流れる。次に美咲と会った時に「最近、全然連絡くれないね」と詰められる
- **効果**: 信頼-5〜-10（放置日数に応じて）、疑念カウント+1
- **設計意図**: まだ修羅場ではなく「不穏な空気」レベル。片方に偏るとペナルティがあることの提示

#### イベント②: カナの匂わせ投稿

- **種別**: SNS受動通知（自動発生）
- **発生条件**: カナ出会い済み＋カナ信頼20以上
- **内容**: カナがインスタに「最近いい感じの人がいる」的な匂わせを投稿
- **効果**: 直接的な実害なし。SNSリスク+2。プレイヤーに「このままだとヤバい」意識を植え付ける
- **発展**: 後の目撃情報イベント（⑥）への伏線

#### イベント③: パチンコの誘惑

- **種別**: ルーティン崩し（ランダム発生）
- **発生条件**: 所持金 ≥ ¥15,000 ＋ 街に出た時 ＋ 10日目以降
- **内容**: 街を歩いていると「新台入替」の看板。ヒモ太郎の「まあいっか」精神が発動
- **選択肢**:
  - 入る → パチンコミニイベント（勝ち/負けのランダム、大負けで家賃危機）
  - 通り過ぎる → himo_aptitude影響なし
- **効果**: 「安定して金を貯める」ルーティンへの直接的な揺さぶり
- **設計意図**: ヒモ太郎のキャラクター性（楽観・衝動的）の表現。所持金が多い時に発生することで「余裕がある時ほど危ない」構造

#### イベント④: カナからの急な呼び出し

- **種別**: 行動制約（強制イベント）
- **発生条件**: カナ出会い済み＋カナ依存 ≥ 20＋昼の行動選択前
- **内容**: 「今すぐ来て」とカナからLINE。断ると信頼-8
- **効果**: 受けると昼＋夜がカナに消費。美咲への連絡・金策の時間がなくなる
- **設計意図**: カナの依存度が上がることのデメリット提示。時間リソースの圧迫

### A-2. 中盤後半（16〜23日）— 修羅場ゾーン

#### イベント⑤: ダブルブッキング危機

- **種別**: 修羅場（嘘パズル発動）
- **発生条件**: 美咲・カナ両方と関係Stage2以上＋同じ日に両方から夜の誘い
- **内容**: 片方を断る必要がある。断り方次第で嘘パズル＋タイマー発動
- **嘘パズルの流れ**:
  1. 「今日仕事が入って」→ 相手「何の仕事？」
  2. 選択肢から矛盾しない回答を選ぶ（制限時間あり）
  3. 前の回答と辻褄が合わないとバレ度UP
- **失敗時**: 信頼大幅DOWN、疑念カウント大幅UP
- **成功時**: 嘘スキル経験値、ただし罪悪感+

#### イベント⑥: 目撃情報

- **種別**: SNS受動通知 → 修羅場（嘘パズル発動）
- **発生条件**: 美咲・カナ両方とデート3回以上＋SNSリスク ≥ 3
- **内容**: SNSに「駅前でカップルっぽい2人見かけた」的な投稿。次に会った時に「これ、あなた？」と聞かれる
- **嘘パズル**: 写真が不鮮明だから言い逃れ可能。ただし矛盾するとバレ度が跳ね上がる
- **設計意図**: SNSリスクシステムの実感。外の世界が見ているという圧力

#### イベント⑦: カナの突撃訪問

- **種別**: ニアミス（証拠隠滅QTE発動）
- **発生条件**: カナ依存 ≥ 40＋美咲と一緒にいる or 美咲関連の証拠がある状態
- **内容**: カナが予告なしに来る。スマホをロック、美咲の私物を隠すなどのQTE
- **QTEの流れ**:
  1. 画面にアイコン表示（スマホ・荷物・LINE通知など）
  2. 制限時間内にクリック/キー入力で処理
  3. 処理し損ねたアイテムごとにバレリスク判定
- **失敗時**: 証拠発見 → 修羅場突入（嘘パズルへ連鎖）
- **成功時**: 危機回避、ただし疑念カウント+1（「なんか慌ててたよね？」）

#### イベント⑧: 美咲の直球質問 ver.2

- **種別**: 修羅場（嘘パズル発動）
- **発生条件**: 疑念カウント ≥ 3＋美咲信頼 ≥ 50
- **内容**: 「他に女の人いるでしょ」と直接聞かれる。Phase 1の5日目疑念イベントの強化版
- **Phase 1との違い**: 具体的な証拠を匂わせてくる（「最近LINE返すの遅いし、予定よく断るし」）
- **嘘パズル**: 難易度高。複数段階の追及に耐える必要あり
- **設計意図**: 疑念カウントの蓄積が実際の結果を生む場面

#### イベント⑨: 所持金バレリスク

- **種別**: パラメータトリガー
- **発生条件**: 所持金 ≥ ¥30,000 の状態で美咲にお金を要求
- **内容**: 美咲「本当にお金ないの？」「最近ちょっと余裕ありそうに見えるけど」
- **効果**: 要求失敗＋疑念カウント+1＋信頼-5
- **設計意図**: ログ1で¥40,000以上持ちながら要求し続けた問題への直接対策。ATMルーティンの崩壊

### A-3. SNS受動通知システム

#### 基本設計

- 朝・昼の行動選択メニュー表示「前」に、条件に応じて自動で差し込まれる
- プレイヤーのターン（行動枠）を消費しない
- 既存の「SNSを見る」選択肢は削除

#### 通知カテゴリ

| カテゴリ | 内容例 | 発生条件 | 効果 |
|---|---|---|---|
| フレーバー | 同級生の昇進・マイホーム報告 | ランダム（既存の流用） | ヒモ太郎の独白のみ |
| カナ匂わせ | 「いい感じの人がいる」投稿 | カナ信頼20以上 | SNSリスク+、プレイヤーへの警告 |
| 美咲の意味深 | 「疲れた...」→依存高いと「会いたい」 | 美咲依存度に連動 | 依存度の可視化 |
| 目撃系 | 「駅前でカップル見かけた」 | SNSリスク ≥ 3 | 修羅場イベント⑥のトリガー |
| ニュース系 | 「若者の恋愛離れ」等 | ランダム | ヒモ太郎のツッコミ、フレーバー |

#### 実装方針

```
morning_actions / afternoon_actions の先頭で
check_sns_notification() を呼び出し
→ 条件に合致する通知があれば表示
→ 通知なしなら何も起きない
→ その後、通常の行動メニューへ
```

## B. デートバリエーション

### 層1: デート先の選択

デート誘い成功後、場所を選べるようにする。場所によって会話内容・パラメータ変動・リスクが異なる。

#### 美咲のデート先

| 場所 | コスト | 信頼 | 依存 | 特殊効果 |
|---|---|---|---|---|
| ファミレス | ¥0（美咲奢り） | +3 | +2 | 安全だが地味 |
| 居酒屋 | ¥0（美咲奢り） | +5 | +5 | 酒で本音が出やすい → 探り発生率UP |
| 美咲の部屋 | ¥0 | +5 | +8 | お泊り発展可能、翌朝強制イベント |
| ちょっといい店 | ¥3,000（自腹） | +10 | +3 | 自分から金を出す＝信頼大幅UP |

#### カナのデート先

| 場所 | コスト | 信頼 | 依存 | 特殊効果 |
|---|---|---|---|---|
| カフェ | ¥0（カナ奢り） | +5 | +3 | インスタ投稿リスク（SNSリスク+2）。序盤は安定択だが、中盤以降SNSリスクが目撃情報イベント⑥に直結し実害が大きくなる |
| カラオケ | ¥500 | +8 | +5 | SNSリスクなし。楽しいが金かかる。中盤のSNSリスク回避先として価値が上がる |
| カナの大学付近 | ¥0（カナ奢り） | +8 | +4 | SNSリスク+1（友達目撃）。カナの友達と会話でき、カナの本音・過去の情報を入手可能（後のイベントで探り回避や地雷回避に有利）。信頼上昇量がカフェより高い |
| ヒモ太郎の部屋 | ¥0 | +5 | +6 | SNSリスクなし・コストなしの唯一の場所。清潔感50以上で信頼+5、30未満だと信頼-3。親密スキル経験値が入る（ステップ3のエナマッチ解禁後に本領発揮） |

#### デート先選択の戦略変化（時期別）

- **序盤（カナ出会い直後）**: カフェ安定。SNSリスクはまだ実害なし
- **中盤前半（SNSリスク蓄積期）**: カフェが怖くなる。大学付近で情報収集 or カラオケで安全にデート
- **中盤後半（修羅場ゾーン）**: 目撃リスクを避けてヒモ太郎の部屋に籠る選択が有効。ただし依存が上がりやすい
- **終盤**: 状況と残りリスクに応じた使い分けが求められる

### 層2: デート中の探り・地雷

デート中の会話で、相手の疑念度やパラメータに応じて「探り」と「地雷」が発生する。

#### 探り（疑念度が高いほど発生率UP）

| 探りの内容 | 発生条件 | 対応 |
|---|---|---|
| 美咲「昨日の夜、何してたの？」 | 疑念 ≥ 1 | 前日の行動と矛盾しない回答が必要 |
| カナ「スマホ見せて？」 | カナ依存 ≥ 40 | 断る→疑念UP / 見せる→LINE通知リスク |
| 美咲「来週の土曜、空いてる？」 | 美咲信頼 ≥ 50 | 安請け合い→カナ側の予定と衝突の伏線 |
| カナ「インスタにツーショット載せていい？」 | カナ信頼 ≥ 30 | 断る→カナ不機嫌 / OK→証拠が残る |
| 美咲「最近、楽しそうだね」 | 疑念 ≥ 2 | 含みのある質問。回答次第で疑念変動 |

#### 地雷（キャラの内面に触れる選択肢）

| 地雷の内容 | キャラ | 効果 |
|---|---|---|
| 「仕事辞めれば？」 | 美咲 | 信頼-15。美咲のアイデンティティ否定 |
| 「フォロワー数とか気にしすぎ」 | カナ | 依存度による。低→信頼-10 / 高→逆に信頼+5（本音で話してくれた） |
| 「俺のこと養ってよ」 | 美咲 | Stage依存。Stage2以下→冗談で済む / Stage3以上→本気で引かれる（信頼-10） |
| 「他の男と遊んでんの？」 | カナ | カナ激怒。信頼-10、依存+5（嫉妬＝好き、と解釈） |
| 「別に会わなくてもよくない？」 | 両方 | 信頼-8、依存-10。突き放し |

#### 設計意図

- 地雷は見た目では分かりにくい。キャラの性格と関係性を理解していれば避けられる
- 知らずに踏むと信頼が大きく落ちる。周回プレイで「これは言っちゃダメ」と学ぶ
- 一部の地雷は状況次第で正解にもなる（「養ってよ」がStage4だと冗談として通る等）

### 層3: デート中のハプニング（ランダム発生）

選択とは無関係にランダムで差し込まれるイベント。

| ハプニング | 発生条件 | 内容 |
|---|---|---|
| もう片方からLINE | 両キャラと関係あり | デート中にLINE通知。既読つけるか無視するか |
| 美咲の同僚とばったり | 美咲デート中＋街 | 紹介する？ごまかす？ |
| カナのインスタ撮影 | カナデート中 | 突然ツーショットを撮ろうとする |
| 財布のレシート | デート中＋直近で別の女とデート済 | 別の店のレシートで探り発生 |
| 知らない番号から着信 | ランダム低確率 | 実はもう片方のキャラの友人。出るか出ないかの判断 |

## C. 修羅場ミニゲーム

### C-1. 嘘パズル＋タイマー

#### コンセプト

追い詰められた状況で、制限時間内に矛盾しない言い訳を複数段階組み立てる。

#### 基本ルール

1. 相手からの質問が表示される
2. 制限時間（嘘スキルに応じて5〜10秒）内に回答を選ぶ
3. 時間切れ → 最悪の回答が自動選択される（「え...あ...」的な沈黙）
4. 選んだ回答に基づいて次の質問が変わる（2〜3段階）
5. 各段階で「矛盾判定」: 前の回答と辻褄が合わないとバレ度UP

#### 嘘スキルとの連動

| 嘘スキルLv | 制限時間 | 選択肢の質 | 矛盾判定 |
|---|---|---|---|
| Lv.0 | 5秒 | しょうもない言い訳が大量に混ざる | 厳しい（少しでも矛盾→バレ度大） |
| Lv.1 | 7秒 | まともな選択肢が増える | 普通 |
| Lv.2 | 10秒 | 質の高い言い訳が並ぶ | 甘い（多少の矛盾は誤魔化せる） |

#### 選択肢の例（嘘スキルLv.0）

```
美咲「昨日の夜、何してたの？LINE返ってこなかったけど」

選択肢（制限時間5秒）:
  ① 寝てた                    ← まとも
  ② 犬の散歩してた              ← 犬飼ってない
  ③ 宇宙のことを考えてた         ← 論外
  ④ バイトの面接があって          ← 夜に面接？

→ ①を選んだ場合
美咲「寝てた？22時に既読ついてたけど？」

選択肢（制限時間5秒）:
  ① 既読つけてからすぐ寝ちゃった  ← 辻褄が合う
  ② 友達と飲んでた              ← 「寝てた」と矛盾
  ③ スマホ誰かに貸してた         ← 怪しすぎる
  ④ 覚えてない                  ← 弱いが矛盾はしない
```

#### バレ度ゲージ

- 画面上に「バレ度ゲージ」を表示（相手の顔の表情変化と連動）
- 矛盾回答: +30〜50
- 沈黙（時間切れ）: +40
- 辻褄が合う回答: +0〜+10（完璧でも微妙に上がることがある）
- ゲージ100%到達: バレ確定 → 修羅場エンド分岐

### C-2. 証拠隠滅QTE

#### コンセプト

物理的な証拠がバレる前に処理する。タイミングと判断のゲーム。

#### 基本ルール

1. 状況説明（「カナがドアの前にいる！」）
2. 画面に処理すべきアイテムがアイコンで表示（3〜5個）
3. 制限時間（10〜15秒）内にクリック or キー入力で処理
4. 処理できなかったアイテムごとにバレリスク判定

#### アイテム例

| アイテム | 場所 | 処理方法 | 未処理時のリスク |
|---|---|---|---|
| スマホ（LINE画面） | テーブル上 | ロックボタン押下 | 相手のメッセージ丸見え |
| 美咲の髪留め | 洗面台 | ポケットに隠す | 「誰の？」 |
| レシート | ジャケットのポケット | ゴミ箱へ | 別の店の証拠 |
| LINE通知音 | スマホ | マナーモードに | 相手の名前が表示 |
| 脱ぎっぱなしの服（女物） | ベッド付近 | クローゼットへ | 致命的 |

#### 難易度調整

- アイテム数: シチュエーションの深刻度に応じて3〜5個
- 制限時間: 状況に応じて10〜15秒
- 一部アイテムは「処理順序」がある（先にスマホをロックしないとLINE通知が鳴る等）

## 実装優先度

### 高（ステップ1で必須）

| 項目 | 理由 |
|---|---|
| SNS受動通知システム | 他のイベントの伏線装置。基盤として先に必要 |
| イベント⑤ ダブルブッキング危機 | 嘘パズルの主要発動ポイント |
| イベント⑨ 所持金バレリスク | 実装コスト低、ATMルーティン対策の即効薬 |
| 嘘パズル＋タイマー（基本形） | 修羅場の核。⑤⑥⑧で共用 |
| デート先の選択（層1） | デートの印象を変える最小コスト |

### 中（ステップ1で可能な限り実装）

| 項目 | 理由 |
|---|---|
| イベント①③④ | 中盤前半の揺さぶり。個別の実装コストは低い |
| イベント⑥⑧ | 嘘パズルのバリエーション |
| デート中の探り・地雷（層2） | デートの深み。テキスト追加が主で実装コストは中程度 |

## テストプレイでの確認ポイント

### 単調さの解消

- [ ] 10〜25日目に「何も起きない」期間が3日以上連続しないか
- [ ] 毎回同じルーティンで30日クリアできてしまわないか
- [ ] カナを完全放置しても何らかの介入（自発的連絡・SNS通知）が来るか

### 修羅場ミニゲーム

- [ ] 嘘パズルの制限時間は焦るが理不尽ではないか（5秒で十分選べるか）
- [ ] しょうもない選択肢が面白いか（「犬の散歩」「宇宙」等）
- [ ] バレ度ゲージの上昇速度は適切か（1回の矛盾で即死しないか）

### デートバリエーション

- [ ] 同じキャラに5回以上会っても毎回違う展開が起きるか
- [ ] 探り・地雷の発生頻度は適切か（毎回だとうざい、3回に1回程度が目安）
- [ ] 地雷を踏んだ時の信頼低下は痛いが致命的ではないか

### バランス

- [ ] 所持金¥30,000超で美咲にお金要求 → ちゃんと拒否されるか
- [ ] 中盤イベントによって難易度が上がりすぎていないか
- [ ] 嘘パズル失敗 → リカバリー手段があるか（即ゲームオーバーでない）
